Beyond the Score: Keep the Cases That Went Wrong

AUC, Dice, and mAP are summaries. Case-level outputs reveal what an average cannot tell us.

EvaluationError Analysis

Sample article · Written to demonstrate the reading layout; not an original publication by the author.

Metrics help compare experiments, but an average cannot describe every failure mode. Keeping predictions and evaluations for individual cases makes it possible to revisit the evidence and later prepare research tables and figures.

Define the evaluation unit first

Image-level, examination-level, and patient-level results answer different questions. Before summarizing, estimating confidence intervals, or resampling, define the independent sampling unit. Multiple images from one patient should not automatically be treated as independent observations.

  • Classification: keep case labels, prediction scores, the preset threshold, and classification results.
  • Detection: keep predicted boxes, scores, annotation matches, and false-positive / false-negative cases.
  • Segmentation: keep masks, case-level metrics, volumes, and spatial information.

Fix evaluation rules before inspecting test results

Define thresholds, matching rules, and exclusion criteria in advance. Repeatedly adjusting them on the test set makes the final score difficult to interpret as independent evaluation. Report exploratory analyses separately from the primary results.

Treat summary.csv as a standard inference output, rather than a file to assemble only when writing the paper.
