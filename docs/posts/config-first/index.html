把路徑移出程式碼，從一份 config 開始

資料位置、模型權重與輸出目錄集中管理，讓同一段程式更容易在不同環境執行。

PythonConfiguration

示範文章 · 此內容用於展示閱讀版面，尚非本人正式發表。

當資料路徑散落在數個 Python 檔案中，換一台機器就可能需要逐行修改。先把輸入、模型、參數與輸出位置集中，是一個小而實用的維護起點。

設定也應該有驗證

  • 啟動時檢查輸入目錄與模型權重是否存在。
  • 明確處理輸出目錄已存在時的行為。
  • 將最終生效的參數保存到每次執行的輸出資料夾。
  • 把需要保密的值與可分享的實驗設定分開管理。

先求簡單，再求通用

小型研究程式可以從 argparse 加一份 JSON 設定開始。當專案確實需要多階層覆寫與大量實驗組合時，再考慮更完整的設定框架。讓設定容易閱讀，比一開始就建立複雜抽象更有價值。
