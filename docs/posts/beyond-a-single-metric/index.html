模型分數之外：把錯誤個案留下來

AUC、Dice 與 mAP 是摘要。逐案輸出與錯誤分析，讓我們看見平均值沒有說完的事。

EvaluationError Analysis

示範文章 · 此內容用於展示閱讀版面，尚非本人正式發表。

指標能幫助比較實驗，但一個平均值無法描述所有失敗情境。把每個個案的預測與評估結果留下來，可以在發現問題時回到原始案例，也方便之後整理研究表格與圖。

先決定評估單位

影像層級、檢查層級與病人層級的結果回答不同問題。做摘要、信賴區間或重抽樣前，先說清楚獨立樣本的單位，避免把同一病人的多張影像當成完全獨立的觀測值。

  • 分類：保存個案標籤、預測分數、預設閾值與分類結果。
  • 偵測：保存預測框、分數、標註對應及 FP / FN 個案。
  • 分割：保存 mask、個案指標、體積與空間資訊。

讓評估規則在看測試結果前固定

閾值、配對方式與排除條件都應事先定義。若在測試集上反覆調整規則，最後的數字就難以代表獨立評估。需要探索性的分析時，將它與主要結果分開說明。

把 summary.csv 當作每次推論的正式輸出，而不是最後寫論文時才補做的檔案。
