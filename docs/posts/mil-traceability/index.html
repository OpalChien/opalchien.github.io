從 patch 到 patient：MIL 的對應關係不能丟

特徵檔之外，還要保存 patch 的來源與位置，才能把 attention 結果帶回原始影像。

MILAttention

示範文章 · 此內容用於展示閱讀版面，尚非本人正式發表。

多實例學習常把影像轉成一組特徵，再以 bag 為單位預測。若只保存特徵矩陣，卻沒有記下每一列來自哪個 patch，之後就很難解釋或檢查模型關注的位置。

特徵與索引，成對保存

  • 定義 bag 與 patient、study 的對應關係。
  • 每個 patch 保存來源檔、座標、尺寸與前處理版本。
  • 確認特徵矩陣列順序與索引清單一致。
  • 依病人分組，避免同一來源的 patch 跨越資料切分。

attention 是檢查入口

attention 權重可用來定位模型在聚合時較重視的實例，但不能直接視為因果解釋或病灶標註。將高權重 patch 帶回原圖，搭配錯誤個案和其他驗證方式，才更容易理解模型行為。
