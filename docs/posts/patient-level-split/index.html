先切病人，再切影像：資料切分的基本功

同一位病人的不同檢查，可能比想像中更相似。把資料的獨立性放在模型訓練之前。

Data LeakageValidation

示範文章 · 此內容用於展示閱讀版面，尚非本人正式發表。

一個影像資料集不一定等於一組獨立樣本。同一位病人可能有多次檢查、一個檢查可能包含不同重建方式，一個 series 又會產生許多切片。若直接打亂所有圖片，這些關聯就容易被忽略。

先建立可追溯的資料清單

先建立每張影像到 patient、study、series 的對應，再依研究問題決定分組層級。一般病人層級預測任務，可先以 patient ID 分組後切分，並另外確認重複匯出、衍生影像與近似副本。

python
# 切分完成後，檢查病人集合是否重疊。
train_ids = set(train_df["patient_id"])
val_ids = set(val_df["patient_id"])
test_ids = set(test_df["patient_id"])

assert train_ids.isdisjoint(val_ids)
assert train_ids.isdisjoint(test_ids)
assert val_ids.isdisjoint(test_ids)

讓切分結果成為研究輸出

  • 保存 split.csv，記錄匿名化 ID、分組與 fold。
  • 固定 seed，並保存實際分組結果。
  • 分別描述每組病人數、檢查數與標籤分布。
  • 確認標準化、特徵選擇與閾值設定只使用允許的訓練或驗證資料。

如果研究目的是評估跨時間、跨院區或跨設備的泛化能力，還需要對應的獨立切分設計。病人不重疊是起點，但不能取代研究問題本身所要求的外部驗證。
