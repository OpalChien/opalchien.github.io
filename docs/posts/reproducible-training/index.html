模型訓練 / 2026.10.12 / 5 分鐘閱讀

讓下一次訓練，能找回這一次的自己

不只設定 seed：把 config、資料切分、checkpoint 與實驗紀錄一起保存，讓結果有跡可循。

PyTorchReproducibility

示範文章 · 此內容用於展示閱讀版面，尚非本人正式發表。

重現一個訓練結果，往往需要比一個 seed 更多的資訊。資料版本、實際 fold、前處理流程、套件版本及 checkpoint 的選擇，都會影響我們如何理解一次實驗。

每個實驗，都有自己的資料夾

text
runs/experiment_001/
  config.json
  split.csv
  environment.txt
  train.log
  metrics.csv
  checkpoints/
    best.pt
    last.pt

分開保存 best 與 last

best checkpoint 依預先定義的驗證集指標挑選；last checkpoint 則用來恢復中斷的訓練。若要 resume，除了模型權重，也需考慮 optimizer、scheduler、AMP scaler、epoch 和亂數狀態。

  • batch size、累積梯度與混合精度設定寫入 config。
  • early stopping 的監控指標、方向與 patience 明確記錄。
  • 每個 epoch 輸出訓練與驗證指標，保留失敗紀錄。
  • 測試集留到實驗設計確定後，用固定的評估流程處理。

不同硬體與運算實作可能仍存在非決定性。比起承諾所有執行都完全相同，更實際的做法是記錄環境、控制已知變因，並用重複實驗描述結果的變異。
