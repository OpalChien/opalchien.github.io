一張 mask 的位置，和它的準確度一樣重要

從 DICOM 到 NIfTI，記錄 spacing、方向與座標空間，避免分割結果在轉換中失去對齊。

DICOMNIfTISegmentation

影像與 mask 的 array shape 相同，不代表它們位於同一個物理空間。處理三維影像時，需要同時追蹤 spacing、origin、direction，以及前處理過程中做過的變換。

分清楚 index 與物理座標

陣列索引描述資料在記憶體中的排列，物理座標則描述影像在空間中的位置。不同影像函式庫可能使用不同的軸順序或座標慣例，轉換前要確認讀取與寫入工具的約定。

  • 讀入時記錄 shape、spacing、origin 與方向矩陣。
  • 每次 crop、resample 或 reorient 都保留可逆的轉換資訊。
  • 將預測結果轉回預定的參考影像空間後再輸出。
  • 用多平面疊圖確認左右、位置及邊界是否對齊。

選擇適合資料的插值方式

離散類別 mask 在重採樣時通常使用 nearest-neighbor，避免引入不存在的類別。影像與機率圖則需依用途選擇插值方法。不要只讓兩者使用相同的目標 shape，還要確認目標座標空間一致。

驗證對齊時，同時看 metadata 與疊圖。單看其中一個，容易漏掉軸順序或方向處理的問題。

輸出也要能回頭檢查

每個個案可保存原始資訊摘要、前處理設定、最終 mask 與代表性疊圖。計算體積時，使用實際輸出空間的 voxel volume，並在結果表中註明單位與計算方式。
